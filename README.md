# Smooth — AI-помощник для диагностики кожи

> Анализируй состояние кожи по фото и получай персонализированные рекомендации по уходу с помощью искусственного интеллекта.

---

## 📱 О проекте

**Smooth** — это веб-приложение с открытым исходным кодом, которое использует возможности искусственного интеллекта для анализа кожи пользователя по загруженному фото.

Проект решает две ключевые задачи:
- 🧬 **Диагностика** — определение типа кожи, выявление покраснений, акне, сухости, пигментации и других признаков.
- 🧴 **Подбор ухода** — персонализированные рекомендации средств по уходу на основе анализа.

**Миссия проекта** — сделать качественную дерматологическую диагностику доступной для каждого, независимо от дохода и местоположения.

---

## ✨ Возможности

- 📸 Загрузка фото кожи через удобный интерфейс
- 🧠 Анализ изображения с помощью ИИ (ChatGPT / OpenAI API)
- 📊 Детальный отчёт о состоянии кожи
- 🛍️ Персональные рекомендации уходовых средств
- 📱 Адаптивный дизайн для всех устройств
- 🔒 Безопасная обработка данных

---

## 🛠️ Технологии

- **AI:** OpenAI API (ChatGPT / GPT-4)

## 🔧 Установка и запуск

1. Клонируй репозиторий:
